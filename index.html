Featured Research

Hierarchical Recursive Causal Feature Selection

For Explainable Schizophrenia Prediction from DNA Methylation

Applying causal machine learning methods to DNA methylation data in schizophrenia, a computational framework for feature selection in classification was developed. The resulting feature set achieved predictive performance comparable to sets obtained using conventional statistical feature reduction methods, while providing the additional benefit of causal interpretability.

The framework combined differential methylation analysis, gene mapping, Weighted Gene Co-expression Network Analaysis (WGCNA), causal discovery, and machine learning into a hierarchical feature-selection pipeline.
